12IActionResult — „ნებისმიერი პასუხი“

⏱ 0:25 · 3 წთ
ASP.NET Core-ს აქვს interface IActionResult. Action — Controller-ის მეთოდი, Result — მისი შედეგი. „Action-ის შედეგი“.
→ 12xx
მას ბევრი კლასი ახორციელებს. წარმატების: OkObjectResult — 200, CreatedAtActionResult — 201, NoContentResult — 204.
→ 24xx
შეცდომის: NotFoundResult — 404, BadRequestObjectResult — 400. და კიდევ ბევრი.
→ 3interface
interface ჰგავს შეთანხმებას: „ვინც მე მახორციელებს, იცის, როგორ გადაიქცეს HTTP პასუხად — რა სტატუსით და რა body-თი“.
→ 4შედეგი
ამიტომ, თუ მეთოდი IActionResult-ს აბრუნებს, მისგან ნებისმიერი ამ კლასის ობიექტი შეგვიძლია დავაბრუნოთ. ერთ if-ში — 404, მეორეში — 200.
კლასების სახელების დამახსოვრება არ არის საჭირო — შემდეგ სლაიდზე ვნახავთ, რომ მათ პირდაპირ თითქმის არასდროს ვქმნით.
