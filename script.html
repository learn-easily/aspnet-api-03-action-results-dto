11DTO — Data Transfer Object

⏱ 0:22 · 4 წთ
DTO — Data Transfer Object. ობიექტი მონაცემის გადასატანად. მასში ლოგიკა არ არის — მხოლოდ ველები.
→ 1Request
ბანკი წარმოიდგინეთ. ანგარიშის გასახსნელად ფორმას ავსებთ: სახელი, პირადი ნომერი, ტელეფონი. ანგარიშის ნომერს ფორმაში არ წერთ — ბანკი გაძლევთ. ეს Request DTO-ა.
→ 2Entity
ბანკის ბაზაში ბევრად მეტია: რისკის შეფასება, ვინ გახსნა, როდის. ეს Entity-ა. გარედან არავინ ხედავს.

ამონაწერი, რომელსაც ბანკი გაძლევთ — მხოლოდ თქვენთვის საჭირო: ნომერი, ნაშთი, ტრანზაქციები. ეს Response DTO-ა.
ერთი ანგარიში — სამი ფორმა. ზუსტად იგივეს ვაკეთებთ პროდუქტისთვის.
